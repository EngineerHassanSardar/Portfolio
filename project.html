Case study

Umar Sons — Web & Mobile

Two linked projects that replaced spreadsheet workflows for a family-owned import/export company in Pakistan. One web dashboard. One Android app. Same API. Same database. Same login.

01

Umar Sons Import & Export — Web

A business management dashboard built with ASP.NET Core MVC (.NET 8), EF Core code-first migrations, and SQL Server. Covers customer management, container loading records, China and Pakistan warehouse inventory, expenses, and customer ledgers — plus 15+ reports, each with client-side PDF and Excel export.

  • ASP.NET Identity with role-based access (Admin, Manager, User)
  • Soft-delete pattern propagated through every list endpoint
  • Multi-branch user scoping
  • jsPDF + autoTable paginated A4 reports
  • SheetJS exports for Excel workflows

Stack: ASP.NET Core · EF Core · SQL Server · TypeScript · jsPDF · SheetJS

02

Umar Sons — Mobile

A native Android app built with .NET MAUI Blazor Hybrid that reuses the Razor components from the web project. Same credentials, same reports, same data — because both clients hit the same API and database.

  • Singleton HttpClient with shared CookieContainer for ASP.NET Identity cookies
  • Ship-themed CSS + SVG loading animation
  • Multi-page branded PDF export on Customer Ledger
  • Base64 PDF handoff from WebView JavaScript to C# File.WriteAllBytesAsync
  • Custom SVG app icon and splash screen (navy #05274D + orange #ff9b44)

Stack: .NET MAUI · Blazor Hybrid · C# · HttpClient · Android

What I learned

ASP.NET Core authentication pipelines (cookies + JWT) MAUI Blazor Hybrid cross-platform development API contract design for multiple clients Android SSL, USB tunneling, file system restrictions Preparing and signing an Android App Bundle (AAB) Keeping two clients in sync via a shared API
