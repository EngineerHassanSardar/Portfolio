I'm a Full Stack Developer at TechnoTech Innovations (Pvt.) Ltd., where I build modern desktop and web applications using the Microsoft .NET ecosystem. My day-to-day work spans C#, .NET MAUI, ASP.NET, and Blazor — with SQL Server as the backbone for data.

I started my journey with a strong curiosity for how software solves real problems. What began as tinkering with small console apps grew into a professional focus on clean architecture, database design, and shipping features that users actually enjoy. I care about the details: naming, structure, readability, and the small UI touches that make software feel polished.

Outside of client work, I enjoy learning new patterns in the .NET space, refining my JavaScript and CSS skills, and exploring how modern web frameworks deliver great experiences with less overhead. I'm based in Peshawar and always open to conversations about software, craft, and collaboration.
